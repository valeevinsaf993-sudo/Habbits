# 🗑 Бот для просмотра удалённых сообщений

Телеграм-бот, который сохраняет сообщения из **ваших** чатов и присылает их
обратно, если собеседник их удалил.

---

## ⚠️ Сначала прочитайте — как это на самом деле работает

Обычный Telegram-бот **не может** читать вашу личную переписку и **не может**
«подсматривать» за удалёнными сообщениями в чужих чатах. Это ограничение
самого Telegram, обойти его нельзя.

Единственный официальный способ получать такие события — функция
**Telegram для бизнеса (Telegram Business)**:

1. Вы **сами** подключаете бота к **своему** аккаунту.
2. Telegram начинает присылать боту события о сообщениях в **ваших** чатах,
   включая официальное событие об удалении (`deleted_business_messages`).
3. Бот логирует проходящие сообщения и, когда одно из них удаляют, присылает
   вам сохранённую копию.

Из этого следуют честные ограничения:

- 🔒 **Нужен Telegram Premium** — без него раздела «Telegram для бизнеса» нет.
- 👤 Бот видит только **ваши** чаты и только после того, как вы его подключите.
  Чужие аккаунты и переписки, в которых вас нет, ему недоступны.
- ⏮ Сообщения, отправленные **до** подключения бота, восстановить нельзя —
  их просто нет в логе.
- 🖼 Если медиа удалено не только из чата, но и с серверов Telegram, бот
  пришлёт хотя бы текст/подпись.

Это легальный инструмент для **вашего собственного** аккаунта (например, чтобы
не терять сообщения клиентов). Он не предназначен для слежки за посторонними.

## 🚀 Установка

Требуется Python 3.10+.

```bash
cd telegram-deleted-messages-bot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # Windows: copy .env.example .env
# впишите BOT_TOKEN в .env
```

---

## 🤖 Шаг 1. Создать бота в @BotFather

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`, задайте имя.
2. Скопируйте токен и вставьте его в `.env` (`BOT_TOKEN=...`).
3. Включите бизнес-режим:
   `/mybots` → ваш бот → **Bot Settings → Business Mode → Turn on**.

> Без включённого Business Mode бота нельзя будет подключить к аккаунту.

---

## 🔗 Шаг 2. Подключить бота к своему аккаунту

В приложении Telegram (нужен Premium):

**Настройки → Telegram для бизнеса → Чат-боты** → введите username вашего бота
→ включите разрешения (чтение/управление сообщениями).

После подключения бот пришлёт вам в личку подтверждение.

---

## ▶️ Шаг 3. Запуск

```bash
python bot.py
```

Бот работает в режиме long-polling — просто держите процесс запущенным
(на сервере удобно под `systemd`, `screen`/`tmux` или в Docker).

Напишите боту в личку `/start`, `/help`, `/status`.

---

## ⚙️ Настройки (`.env`)

| Переменная       | Назначение                                             | По умолчанию |
|------------------|--------------------------------------------------------|--------------|
| `BOT_TOKEN`      | Токен от @BotFather                                    | —            |
| `DB_PATH`        | Путь к файлу базы SQLite                                | `messages.db`|
| `RETENTION_DAYS` | Сколько дней хранить логи (`0` — хранить бессрочно)     | `30`         |

---

## 🧩 Как устроено

| Файл              | Назначение                                              |
|-------------------|---------------------------------------------------------|
| `bot.py`          | Логика бота и обработчики бизнес-событий                |
| `storage.py`      | Хранилище на SQLite (подключения и сообщения)           |
| `requirements.txt`| Зависимости                                             |

События Telegram, которые обрабатывает бот:

- `business_connection` — подключение/отключение бота к аккаунту;
- `business_message` — новое сообщение в вашем чате → сохраняем копию;
- `edited_business_message` — редактирование → обновляем копию;
- `deleted_business_messages` — удаление → присылаем сохранённую копию вам.

---

## 🔐 Приватность

- Все данные хранятся **локально** в SQLite-файле у вас (`DB_PATH`).
- Файл `.env` и база данных добавлены в `.gitignore` и не попадают в репозиторий.
- Используйте бота только для своего аккаунта и в рамках закона вашей страны
  о персональных данных и переписке.
